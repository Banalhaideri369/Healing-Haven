⚠️ تنبيهات مهمة
🚫 الـ API Server لا يعمل على Netlify مباشرة
الـ Backend هو Express Server كامل — Netlify تستضيف Static Sites فقط.
الحل: استضف الـ API Server على Railway أو Render أو Fly.io، ثم أضف متغير VITE_API_BASE_URL في الـ Frontend يشير لرابط الـ API الجديد.
🚫 Stripe متصل عبر Replit Connector
الكود يستخدم REPLIT_CONNECTORS_HOSTNAME الخاص بـ Replit فقط — لن يعمل على Netlify أو أي استضافة أخرى.
الحل: عند الاستعداد لربط Stripe، أضف المتغير STRIPE_SECRET_KEY مباشرة وعدّل الكود ليستخدمه.
ℹ️ متغيرات VITE_ للـ Frontend
أي متغير يبدأ بـ VITE_ يجب إضافته في Netlify ضمن:
Site Settings → Environment Variables
وسيكون متاحاً فقط وقت البناء (npm run build).
